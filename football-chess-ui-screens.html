1. User Onboarding Screens

1.1 Welcome & Login Screen

The initial screen users see when opening the game for the first time. It provides login options and introduces the game concept.

UI Elements:

  • Game logo and branding ("FootballChess" with football and chess elements)
  • Login form (email/username and password fields)
  • Social login options (Google, Facebook, Apple)
  • Create Account button
  • Guest Play option
  • Background showcasing premium football cards to generate interest

Design Note: Take advantage of the larger screen space to show more information at once. Use multi-column layouts and keep important information visible at all times.

9.2 Desktop Gameplay Controls

Keyboard and mouse optimized controls for desktop gameplay.

UI Elements:

  • Clickable game board with hover states
  • Right-click context menus for quick actions
  • Keyboard shortcuts (arrow keys for navigation, number keys for actions)
  • Minimap for pitch overview
  • Detailed player stats sidebar
  • Drag-and-drop functionality for player movement

Design Note: Implement robust keyboard controls for power users. Show keyboard shortcut hints in the interface to help users learn them.

12. Visual Style Guide

12.1 Color Palette

Primary color scheme and usage guidelines for consistent visual identity.

UI Elements:

  • Primary colors: Deep blues (#0D47A1, #1A237E) for headers and primary UI
  • Secondary colors: Grass greens (#388E3C, #2E7D32) for pitch and game elements
  • Accent colors: Gold (#FFC107) for highlights and premium elements
  • Alert colors: Red (#F44336) for warnings, Green (#4CAF50) for success
  • Neutral colors: Grays and whites for backgrounds and text
  • Team colors: Home (red variants) and Away (blue variants)

Design Note: The color scheme should evoke both football (through field greens) and strategy games (through deep blues). Use gold accents to convey premium value in the card collecting aspects.

12.2 Typography

Font selections and text styling guidelines for the game interface.

UI Elements:

  • Primary font: Sans-serif font family for clear legibility (Arial, Roboto, or similar)
  • Heading text: Bold weight, slightly condensed for titles
  • Body text: Regular weight with good line spacing
  • Button text: Medium or semibold weight
  • Card typography: Bold for player names, condensed for statistics
  • Minimum font size guidelines for readability

Design Note: Use typography hierarchy consistently to guide users' attention. Ensure all text is readable on various backgrounds and screen sizes.

12.3 Iconography

Icon style and usage guidelines for consistent visual communication.

UI Elements:

  • Navigation icons (Home, Shop, Collection, etc.)
  • Action icons (Pass, Shoot, End Turn)
  • Status icons (Injury, Cards, Ball Possession)
  • Player position icons (GK, DEF, MID, FWD)
  • Currency and resource icons
  • Movement pattern indicators

Design Note: Use a consistent stroke weight and style for all icons. Icons should be simple and instantly recognizable, combining football conventions with chess-like strategic elements.

12.4 Animation Guidelines

Standards for animations and transitions throughout the interface.

UI Elements:

  • Transition timing standards (150-300ms for UI elements)
  • Easing functions for smooth motion
  • Card movement and action animations
  • Loading and progress indicators
  • Celebratory animations for rewards and achievements
  • Interactive feedback animations

Design Note: Animations should enhance the experience without causing delays. Use subtle animations for common actions and more elaborate ones for significant events like scoring goals or opening premium card packs.
